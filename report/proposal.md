> 請簡單描述研究問題與動機。研究方法方面，請討論預計所使用的資料以及研究設計，如想要計算的敘述統計量、統計圖表或是迴歸模型。

### 研究問題

小組的專題主題為「大學生審美觀對交友之影響」，在此主題下我們將研究大學生面對初次見面、僅能以外表作為建立第一印象時，外表的差異會如何影響交友意願，並藉此歸納出外表上具有哪些特徵會較為符合大學生的審美觀。

### 研究動機

此次主題的研究動機有兩點，第一是外表對於大學生交友的影響幅度，此更能進而將實驗對象區分男女性觀察性別的差異；第二是哪些五官上的特徵可能在大學生這個族群中，被視為是「好看的」，例如眼睛的大小、臉型、五官比例等。當然，並非當所有特徵皆符合時便是一位被公認好看的人，我們可藉由實驗提供不同的特徵組合，挖掘哪些特徵皆有時較符合大學生的審美觀。本次的實驗期望的學習及影響如下：

1. **利用可量化之數據了解大學生族群普世審美觀：** 每個人對於「美」、「帥」的定義皆不同，然而我們期待藉由這次的專題突破原先的限制，調整問卷的設計方式，將長相數值化。
2. **將日常生活與資料科學結合：** 無論是「交友」或是「容貌」，對於大多大學生而言皆是一個感到焦慮的課題，尤其容貌通常影響了交友，無論是建立男女朋友關係或是一般交友皆使然。事實上，透過國內外相關資料發現容貌甚至會影響學業、工作。本次的專題限縮在容貌對於交友的影響，並且從中觀察到底如何的容貌才是好看的，希望能將資料科學的學問套用在大學生常見的煩惱上。

### 資料來源

以下是我們的資料來源：

本次專題使用的資料來源為自行發放的問卷，將在各大學交流版上發放。 會將受試者分為兩群，分別填寫 A、B 版問卷，以了解在個性、工作經歷等非外表因素不變下，若長相不同，是否會造成交友意願的差異。問卷將挑選數張人像照，並為這些照片在後台建立關鍵字，例如：單眼皮 / 有暴牙等。緊接著詢問受試者以下四個問題：

1. 若您在交友軟體上看見此人，您是否有意願與他建立好友關係？
2. 依據此人的外表，您認為他具有哪些優點、缺點呢？
3. 您會給此人的外表評幾分？
4. 依據此人的外表，您認為他具有以下哪些特徵？

以上問題將全為選擇題，並且設計問卷時會將選項更加具體描述，以讓受試者更能評斷自己的想法為何。

就本組討論目前的資料限制及擔憂有兩者，分別為問卷設計方式和樣本數。在問卷設計方式上，我們需多方採納相關資料，以了解在詢問外表評分時如何呈現問題及說明可讓受試者更能填答符合心中想法。在樣本數上，目前擔憂收集回來的樣本數有限，欲透過小組成員不同的交友網絡發放到各大學校交流版，並且以有趣吸引人的文案邀請大家參與填寫。

### 研究方法

本次的問卷在回收後皆會由數值形式呈現，便於進行資料分析。預計將利用集群分析進行後續研究。以集群分析的方式了解五官上的哪些特徵組合會最能呈現出符合大學生的普世審美觀，並且驗證外表對於交友影響幅度、第一印象是否有顯著差異。

小組期待可藉由集群分析後的結果，能提出各特徵呈現外表好看的相關性。而此方法的限制及擔憂為是否最終的產出結果不夠顯著，或是影響程度小，為此我們的解方包含多設立問題驗證點，也就是交友意願、優缺點、特徵等多方面向，即使最後的產出我們發現僅有一項是符合我們的期待，仍是一個很重大的洞察

## 4. 假說與預期主要結果（組員共同討論，DA 負責撰寫）

> 請描述你們的假說，可以搭配（假想的）統計圖表或是迴歸模型做解釋。P.S. 想要製作 data application 的組別，請提供 UI 示意圖。

本研究提出的主要假說為：在僅透過人臉圖片形成第一印象的問卷情境中，受訪者對圖片人物的外表吸引力評分越高，其初步交友意願也越高。我們提出此假說的理由是人的第一印象某些程度上是建立在外表上。

若假說獲得資料支持，預期外表吸引力評分較高的觀察值，整體上也會呈現較高的交友意願。我們將以圖表呈現兩者的關係，並依實際資料結構選擇分析方法，報告關聯的方向、大小與不確定性。

若未觀察到清楚的正向關聯，則表示本次資料未充分支持此假說；可能涉及關聯較弱、樣本不足或衡量方式的限制，不能直接推論外表完全不重要。研究結論將限於本次受訪者、圖片及問卷情境。
